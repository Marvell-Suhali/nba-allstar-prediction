# NBA All-Star Prediction via Player Similarity Network

DSC 148 – Intro to Data Mining | Course Project | UCSD 2026

## Overview
This project builds a **player similarity graph** from NBA stats and uses graph features (PageRank, degree centrality, clustering coefficient) alongside traditional stats to predict whether a player will be named an NBA All-Star.

## Dataset
- **Source:** [nba_api](https://github.com/swar/nba_api) + [Basketball-Reference](https://www.basketball-reference.com/allstar/)
- **Size:** ~15,000+ player-seasons (2000–2024)
- **Features:** Points, assists, rebounds, steals, blocks, FG%, TS%, USG%, PIE, NET_RATING, and more

## Model
1. Compute cosine similarity between player stat vectors
2. Build a graph: nodes = player-seasons, edges = similarity ≥ 0.92
3. Extract graph features: PageRank, degree centrality, clustering coefficient
4. Train Random Forest on stats + graph features
5. Compare against Logistic Regression and Naive Bayes baselines
